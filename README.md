## 📥 Installation

1. Go to the [Releases](../../releases) section of this repository and download the latest `.vsix` file (e.g., `Echo-1.0.0.vsix`).

2. Open VS Code and run the following command in your terminal:

```bash
code --install-extension Echo-1.0.0.vsix
````


## 🛠️ Requirements
- Ollama installed and running locally.
- Visual Studio Code v1.60.0 or higher.
